# 로드맵 진행 상태 관리

## 개요
사용자의 현재 학습 진행 상태(주차 및 일차)를 관리하고, 일별 TODO 조회를 위한 상태 관리 시스템입니다.

---

## 상태 관리 구조

### roadmapStore
로드맵 데이터와 함께 현재 진행 상태를 관리하는 Zustand store입니다.

```typescript
interface RoadmapStore {
  // 로드맵 데이터
  roadmapId: string | null;
  roadmapData: RoadmapData | null;
  
  // 진행 상태
  currentWeek: number;  // 현재 주차 (1부터 시작)
  currentDay: number;   // 현재 일차 (1~7)
  maxWeek: number;      // 로드맵의 최대 주차
  
  // 액션
  setRoadmap: (id: string, data: RoadmapData) => void;
  clearRoadmap: () => void;
  setCurrentWeek: (week: number) => void;
  setCurrentDay: (day: number) => void;
  incrementDay: () => void;
}
```

---

## 상태 값 범위

### currentDay
- **범위**: 1 ~ 7 (정수)
- **의미**: 현재 주차 내에서의 일차
- **기본값**: 1

### currentWeek
- **범위**: 1 ~ maxWeek (정수)
- **의미**: 현재 진행 중인 주차
- **기본값**: 1

### maxWeek
- **계산 방식**: 로드맵 생성 시 `weeks` 배열에서 최대 week 값 추출
- **예시**: 12주 로드맵이면 maxWeek = 12

---

## 주요 기능

### 1. 로드맵 설정 (setRoadmap)

로드맵 데이터를 저장하고 진행 상태를 초기화합니다.

```typescript
setRoadmap(roadmapId, roadmapData);
```

**동작**:
1. 기존 진행 상태 초기화 (currentWeek: 1, currentDay: 1)
2. roadmapData의 weeks 배열에서 최대 week 값 계산
3. maxWeek 설정
4. roadmapId와 roadmapData 저장

**예시**:
```typescript
// 12주 로드맵 생성 시
setRoadmap('roadmap_123', {
  roadmapId: 'roadmap_123',
  title: '백엔드 개발 로드맵',
  weeks: [
    { week: 1, title: '...' },
    { week: 2, title: '...' },
    // ...
    { week: 12, title: '...' }
  ]
});

// 결과:
// currentWeek: 1
// currentDay: 1
// maxWeek: 12
```

---

### 2. 로드맵 초기화 (clearRoadmap)

로드맵 데이터와 진행 상태를 모두 초기화합니다.

```typescript
clearRoadmap();
```

**동작**:
- roadmapId: null
- roadmapData: null
- currentWeek: 1
- currentDay: 1
- maxWeek: 1

**사용 시점**:
- 새로운 로드맵 생성 전
- 로그아웃 시
- 로드맵 삭제 시

---

### 3. 주차 설정 (setCurrentWeek)

현재 주차를 직접 설정합니다.

```typescript
setCurrentWeek(week);
```

**유효성 검사**:
- week가 1 이상 maxWeek 이하인 경우만 설정
- 범위 밖의 값은 무시

**예시**:
```typescript
// maxWeek = 12인 경우
setCurrentWeek(5);  // ✅ 설정됨 (currentWeek: 5)
setCurrentWeek(15); // ❌ 무시됨 (범위 초과)
setCurrentWeek(0);  // ❌ 무시됨 (범위 미만)
```

---

### 4. 일차 설정 (setCurrentDay)

현재 일차를 직접 설정합니다.

```typescript
setCurrentDay(day);
```

**유효성 검사**:
- day가 1 이상 7 이하인 경우만 설정
- 범위 밖의 값은 무시

**예시**:
```typescript
setCurrentDay(3);  // ✅ 설정됨 (currentDay: 3)
setCurrentDay(8);  // ❌ 무시됨 (범위 초과)
setCurrentDay(0);  // ❌ 무시됨 (범위 미만)
```

---

### 5. 일차 증가 (incrementDay)

현재 일차를 1 증가시키고, 필요시 주차를 자동으로 증가시킵니다.

```typescript
incrementDay();
```

**동작 로직**:

1. **currentDay < 7인 경우**
   - currentDay를 1 증가
   - currentWeek는 유지

2. **currentDay = 7이고 currentWeek < maxWeek인 경우**
   - currentDay를 1로 리셋
   - currentWeek를 1 증가

3. **currentDay = 7이고 currentWeek = maxWeek인 경우** (마지막 주차의 마지막 날)
   - currentDay를 1로 리셋
   - currentWeek는 유지 (더 이상 증가하지 않음)

**예시**:
```typescript
// 케이스 1: 주차 중간
currentWeek: 2, currentDay: 3
incrementDay() → currentWeek: 2, currentDay: 4

// 케이스 2: 주차 마지막 날 (중간 주차)
currentWeek: 2, currentDay: 7
incrementDay() → currentWeek: 3, currentDay: 1

// 케이스 3: 전체 로드맵 마지막 날 (maxWeek = 12)
currentWeek: 12, currentDay: 7
incrementDay() → currentWeek: 12, currentDay: 1
```

## 일별 TODO 조회 연동

### API 엔드포인트
```
GET /api/roadmaps/{roadmapId}/weeks/{weekNumber}/days/{dayNumber}
```

### 사용 예시

```typescript
import { useRoadmapStore } from '@/store/roadmapStore';

const TodoPage = () => {
  const { roadmapId, currentWeek, currentDay } = useRoadmapStore();

  useEffect(() => {
    if (!roadmapId) return;

    // 현재 주차/일차의 TODO 조회
    const fetchTodos = async () => {
      const response = await fetch(
        `${BASE_URL}/api/roadmaps/${roadmapId}/weeks/${currentWeek}/days/${currentDay}`
      );
      const data = await response.json();
      
      // data.todos 사용
      console.log('오늘의 TODO:', data.todos);
    };

    fetchTodos();
  }, [roadmapId, currentWeek, currentDay]);

  return (
    <div>
      <h1>Week {currentWeek}, Day {currentDay}</h1>
      {/* TODO 목록 렌더링 */}
    </div>
  );
};
```

```json
  "roadmapId": "roadmap_123",
  "roadmapData": { /* 로드맵 전체 데이터 */ },

  "currentDay": 5,
  "maxWeek": 12
}
```

## 사용 시나리오

### 시나리오 1: 로드맵 생성 후 첫 학습 시작

```typescript
// 1. DurationSelect에서 로드맵 생성
const response = await fetch('/api/roadmaps', { /* ... */ });
const data = await response.json();

// 2. Store에 저장 (자동으로 currentWeek: 1, currentDay: 1 설정)
clearRoadmap();
setRoadmap(data.roadmapId, data);

// 3. RoadmapView로 이동
navigate(`/roadmap/${data.roadmapId}`);

// 4. TODO 페이지에서 Week 1, Day 1의 학습 시작
```

---

### 시나리오 2: 하루 학습 완료 후 다음 날로 이동

```typescript
// 1. 오늘의 모든 TODO 완료
const completeTodo = async (todoId) => {
  await fetch(`/api/todos/${todoId}/complete`, { method: 'POST' });
};

// 2. 모든 TODO 완료 확인 후 다음 날로 이동
const allCompleted = todos.every(todo => todo.isCompleted);
if (allCompleted) {
  incrementDay(); // currentDay 자동 증가 (필요시 currentWeek도 증가)
  navigate('/roadmap'); // 다음 날 학습 페이지로 이동
}
```

---

### 시나리오 3: 특정 주차/일차로 직접 이동

```typescript
// 주차별 네비게이션
const goToWeek = (weekNumber) => {
  setCurrentWeek(weekNumber);
  setCurrentDay(1); // 해당 주차의 첫날로 이동
};

// 일차별 네비게이션
const goToDay = (dayNumber) => {
  setCurrentDay(dayNumber);
};
```

---

### 시나리오 4: 새로운 로드맵 생성

```typescript
// 1. 기존 로드맵 데이터 삭제
clearRoadmap();

// 2. 새 로드맵 생성 API 호출
const response = await fetch('/api/roadmaps', { /* ... */ });
const newRoadmap = await response.json();

// 3. 새 로드맵 저장 (진행 상태 자동 초기화)
setRoadmap(newRoadmap.roadmapId, newRoadmap);
```

## 주의사항

### 1. maxWeek 계산
- 로드맵 생성 시 weeks 배열이 비어있지 않은지 확인 필요
- 빈 배열인 경우 maxWeek는 1로 설정됨

### 2. 범위 검증
- setCurrentWeek와 setCurrentDay는 자동으로 범위 검증
- 잘못된 값을 설정해도 무시되므로 안전

### 3. incrementDay 사용
- 마지막 주차의 마지막 날에서 incrementDay 호출 시 주차는 증가하지 않음
- 로드맵 완료 후에도 안전하게 사용 가능

### 4. 데이터 동기화
- 서버에서 진행 상태를 관리하는 경우, 주기적으로 동기화 필요
- API 응답의 currentWeek/currentDay와 store 값을 비교하여 업데이트
